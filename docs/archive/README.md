# Supporting archive

`photo_labels_draft.json` is the manually annotated draft formerly committed as
`data/main.py`. It is valid JSON, differs from `data/photo_labels.json`, and has
been preserved for provenance rather than discarded as a duplicate. No runtime
code reads it. The final labels remain in `data/photo_labels.json`.

Historical evaluation outputs, including errors and console logs, remain intact
under `evaluation/runs/`. Demo screenshots remain under `docs/demo/`.

`CODE_MAP_PRE_CLEANUP.md` preserves the earlier line-by-line viva index. Its
cloud, retrieval and evaluation descriptions are historical. Use the current
[requirement-to-code map](../CODE_MAP.md) for navigation.
